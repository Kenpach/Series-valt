# Series-valt (Anime/Series Tracker) — Frontend

This repository contains the **Next.js** frontend for the SeriesVault/Anime Tracker MVP.

## Setup

1) Install deps:
```bash
npm ci
```

2) Create your env file:
- copy `ENV_EXAMPLE.txt` to `.env` and fill the values.

3) Run dev:
```bash
npm run dev
```

## Notes
- `.env` is intentionally **not committed**.
- Build output (`.next/`) and `node_modules/` are ignored.
